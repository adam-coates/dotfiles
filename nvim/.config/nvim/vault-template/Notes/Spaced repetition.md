# Spaced repetition

Review just before you would forget. The intervals grow each time it works.

> [!example] In this vault
> See [[Flashcards]]. Two decks to try: [[German]] and [[Brain facts]].

The forgetting curve is roughly

$$
R = e^{-t/S}
$$

where $S$ is how stable the memory is. Sleep seems to raise $S$ for free.
