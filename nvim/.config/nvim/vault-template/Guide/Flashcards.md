# Flashcards

A note tagged `#flashcards` (or `#flashcards/something`) can hold cards. See [[German]] and [[Brain facts]].

- `Question::Answer` is one card
- `Term:::Meaning` is two, one each way
- A question, a line with `?`, then the answer: for longer ones
- `==highlighted words==` become gaps to fill

`<Space>kk` reviews what is due, `<Space>kd` picks a deck, `<Space>ks` shows the next two weeks. Space shows the answer; 1 to 4 say how it went.

The schedule is a comment next to each card, in the format of Obsidian's Spaced Repetition plugin.
