# Zotero

`<Space>zz` searches your Zotero library. `Enter` makes a literature note with the abstract and your PDF annotations, `Ctrl-l` inserts the citation, `Ctrl-o` opens the item in Zotero. `<Space>zu` adds annotations made since.

Type `@` and a name for citation keys. On a key, `<Space>zi` shows the reference and `<Space>zo` opens the PDF.

Zotero's database is only read. The path is in the settings; without a database all of this is off.
