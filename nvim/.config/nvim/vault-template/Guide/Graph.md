# Graph

`<Space>pg` opens the graph in the browser, `<Space>pl` starts with the notes around this one. It follows you: the ring is the note you are in. Click a node to open it here.

`/` searches, `l` switches to the local graph, `t` shows tags, `f` fits everything. Click a folder in the legend to hide it.

`<Space>pt` shows the neighbourhood of this note without leaving the terminal.
