# Tasks and agenda

Tasks are checkboxes anywhere in the vault, in the format of Obsidian's Tasks plugin.

- [ ] A plain task
- [ ] With a date 📅 @@day+2@@
- [ ] Important and repeating ⏫ 🔁 every week 📅 @@day+5@@
- [/] In progress
- [x] Done ✅ @@day-1@@
- [-] Cancelled

`Enter` ticks the task under the cursor. Try it on the repeating one: the next occurrence appears above it.

| Key          | What it does                            |
| ------------ | --------------------------------------- |
| `<Space>ta`  | add a task from anywhere                |
| `<Space>tt`  | the agenda                              |
| `<Space>tx`  | tick, or make the line a task           |
| `<Space>tc`  | next status                             |
| `<Space>td`  | due date, in words                      |
| `<Space>ts`  | scheduled date                          |
| `<Space>tp`  | priority                                |
| `<Space>tr`  | repeat                                  |
| `]t` `[t`    | next and previous open task             |

Adding takes plain language: `Call Anna tomorrow !high #phone`, or `Water the plants every 3 days`.

In the agenda: `x` done, `>` and `<` move a day, `d` date, `p` priority, `Enter` go to the task, `f` filter.
