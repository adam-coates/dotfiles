## The keys to know

| Key            | What it does                                     |
| -------------- | ------------------------------------------------ |
| `<Space>?`     | every key                                        |
| `<Space>`      | wait a moment: a menu                            |
| `Enter`        | follow link or tag, tick task, fold heading      |
| `Backspace`    | go back                                          |
| `K`            | peek at a link                                   |
| `<Space><Space>` | find or create a note                          |
| `<Space>/`     | search the text of all notes                     |
| `<Space>.`     | the panel on the right                           |

Settings are in `lua/settings.lua` (`<Space>ws`). Point `vaults` at your own folder when you are done with this one.
