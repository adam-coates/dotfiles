# Kanban boards

A board is a note with `kanban-plugin: board` in its properties, headings for columns and tasks for cards. The Obsidian Kanban plugin reads the same files.

Open [[Thesis board]] and press `<Space>tK`, or pick a board with `<Space>tk`.

- `hjkl` move around, `HJKL` move the card
- `a` add, `e` edit, `x` tick, `@` date, `d` delete, `n` new column
- `Enter` opens the note behind a card, and creates it the first time
- `o` goes to the text, `u` undoes, `q` closes

Moving a card moves its lines and nothing else, so anything you add to the note by hand stays.
