# Canvas and mind maps

A canvas is an Excalidraw drawing saved as an SVG in the Canvas folder, with the drawing inside it. In a note it is an ordinary image, so it shows here, in the browser preview, in exports and in Obsidian. `Enter` on it opens it again for editing.

- `<Space>iw` makes a new canvas below the cursor and opens the editor in the browser.
- `<Space>im` in a list (or with lines selected) turns the list into a mind map. Elsewhere in a note, it uses the headings.
- In the editor, **+ Note** (or `Shift-N`) adds a note as a card with its first line. Its link opens the note here.
- Everything else is Excalidraw: shapes, arrows, freehand, images, text. It saves as you go.

Try it: put the cursor in this list and press `<Space>im`.

- Memory
  - Encoding
    - Attention
  - Consolidation
    - Sleep
    - Replay
  - Retrieval

The editor loads Excalidraw from esm.sh, so the first time needs a connection. Viewing a canvas needs nothing.
